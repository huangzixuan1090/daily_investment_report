## 再修正：Sogou 索引不稳定 + 手动文章兜底

### 问题
用户再次截图显示该号**今天（7/27）也发了文章**《黄金突破多头计划价格.. 260727》，此前还有 7/20《什么时候可以抄底科技？》。复搜后发现：
- Sogou 按账号名「地平线全球策略」搜索结果极不稳定：有时能出 7/17 Mundell 文章，有时完全不出；7/20、7/27 在账号名搜索结果里基本不出现。
- 按**精确标题**搜索能命中 7/27、7/20 的 Mundell 文章，但标题未知，无法预先搜索。
- 直接访问 `mp.weixin.qq.com` 文章链接会被微信反爬验证页拦截（`wappoc_appmsgcaptcha`），无法自动抓正文。

结论：**Sogou/微信均无法保证同天/近天文章被自动抓取**。

### 修改
- `config.json`：`wechat.accounts` 中「地平线全球策略」增加 `manual_articles: []` 字段，说明更新为可配置 `{name, aliases, manual_articles}`。
- `lib/wechat.py`：
  - 移除自动抓取 mp.weixin.qq.com 的尝试（会被反爬）。
  - 新增手动文章合并：用户把文章标题/日期/链接/摘要贴进 `manual_articles`，模块会与 Sogou 结果合并、去重、按日期排序后进入总结与渲染。
  - 手动文章默认 source = 账号名，默认 date = 数据日期。

### 用法
在 `config.json` 里按如下格式补充想兜底的文章：
```json
{
  "name": "地平线全球策略",
  "aliases": ["Mundell的分享圈", "Mundell"],
  "manual_articles": [
    {
      "title": "黄金突破多头计划价格，做多止损放在这里.. 260727",
      "date": "2026-07-27",
      "url": "https://mp.weixin.qq.com/s/...",
      "snippet": "（从微信复制的文章开头摘要）"
    }
  ]
}
```
然后重跑 `./run.sh --no-send` 或 `./run.sh` 即可把该文纳入总结。

### 备注
- 这是当前免费/自动化方案下的最优解：Sogou 索引 + 手动兜底。
- 如需完全自动化实时抓取，需要接入付费微信监控服务（如新榜、微小宝）或自行维护微信客户端自动化，成本/复杂度较高。
