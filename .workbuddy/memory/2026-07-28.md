## 新增：全市场 A股 日线缠论买点扫描（并发，绕过 akshare V8）
- 需求：用户要求「扫描全市场所有 A股，一周之内的日线级别缠论买点机会」。
- 重大坑①：本环境 eastmoney / sse.com.cn / szse.cn 列表接口**全部超时**（透明代理或网络限制），只有 sina 源可用。`ak.stock_info_a_code_name` 用 sse → 超时；`stock_zh_a_spot`(sina 分页)也中途超时。改用 sina `hs_a` 节点 `getHQNodeData`(分页 70 页)拉全量代码清单，得 5532 只（沪深A股过滤北交所后 5201 只）。清单当日缓存 `cache/a_codes_YYYYMMDD.json`。
- 重大坑②：**akshare `stock_zh_a_daily` 内部用 `py_mini_racer`(V8) 解密 sina JS，非线程安全**——`ThreadPoolExecutor` 并发必崩(`libmini_racer` FATAL Crash)。已重写 `fetch_daily` 绕过 akshare：直接 requests 调 sina `CN_MarketData.getKLineData`(plain JSON，无 V8) + `qfq.js`(用 `eval` 解析因子字典，无 V8)，qfq 调整=`raw / qfq_factor` 按日期 ffill。线程安全，12-16 并发稳。
- 新增 `scan_all_a_buy(cfg, max_workers=16, within_trading_days=5)`：拉清单→线程池并发~5200只→只保留「买点且 signal_date 在最近 within_trading_days 个交易日」的标的，按 score 降序+信号越新越靠前。引擎 `_mk` 已返回 `signal_date`，`get_chanlun_a`/`scan` 均记录 `signal_date`+`signal_age`(距今天数)。`socket.setdefaulttimeout(30)` 防挂起，`_analyze_one` 带 1 次重试，每 250 只落盘缓存。
- 渲染：`render.chanlun_a_table` 加 `show_date` 列（信号日+距今天数）；新增 `render.render_chanlun_scan_html` 生成独立扫描报告。
- 实测：60 只/12 线程 49.8s(0 失败)；全市场~5200只后台启动，约 2.4 只/s，ETA ~40-90 分钟。报告输出 `reports/chanlun_a_buy_scan_YYYYMMDD.html`。
