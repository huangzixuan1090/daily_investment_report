# 缠论选股 v2.1

基于缠中说禅《教你炒股票》系列提出的缠论理论，对A股进行技术分析，识别笔、中枢、背驰与三类买卖点，辅助选股决策。**新增周线默认支持与信号强度评级。**

## 核心概念

- **包含关系处理**：相邻K线存在包含时，按趋势方向合并
- **顶底分型**：三根经包含处理后的K线中，中间最高为顶分型，中间最低为底分型
- **笔**：从顶分型到底分型（或反之）的连线，中间至少间隔1根独立K线
- **中枢**：至少3笔重叠区间构成的价格密集成交区域
- **背驰**：趋势力度衰竭的信号，分趋势背驰和盘整背驰
- **三类买卖点**：第一类=趋势背驰反转点，第二类=回调不破中枢，第三类=突破回踩确认

## v2.1 升级内容

1. **双数据源容灾**：AKShare（主，稳定量大）→ 新浪财经（备用），任一源失败自动切换
2. **数据量扩展**：默认获取1000个交易日（原500），覆盖更长周期中枢
3. **策略回测**：基于买卖点信号自动回测，输出收益率/胜率/超额收益/交易明细
4. **多级别分析**：支持日线+30分钟联合分析（`--multi-level`）
5. **中枢笔画统计**：中枢内笔画数量可见，辅助判断中枢强度
6. **🆕 信号强度评级**：对买卖点信号进行A/B/C三级评级（A级=多级别共振，B级=单级别确认，C级=初步信号）
7. **🆕 周线默认支持**：`--period weekly` 现已稳定可用，适合中长线分析
8. **🆕 降级重试优化**：数据源切换时自动重试3次，减少偶发超时失败

## 工作流程

1. **解析输入**：提取股票代码（支持6位数字或带市场前缀）
2. **获取行情**：优先AKShare获取K线数据（前复权，默认1000根），失败降级新浪
3. **执行分析**：调用 `python scripts/chanlun_analyzer.py --codes "代码1,代码2"` 运行分析
4. **回测验证**：自动对买卖信号进行策略回测，给出胜率和收益率
5. **信号评级**：根据多级别共振情况对买卖点进行A/B/C评级
6. **解读结果**：重点说明笔方向、中枢区间、背驰信号、买卖点、信号评级、回测表现
7. **给出建议**：基于分析+回测综合给出建议，必须声明不构成投资建议

## 输入格式

用户可以提供：
- 单只股票：`"帮我分析 000001 的缠论结构"`
- 多只股票：`"用缠论分析 000001,600519,300750"`
- 指定周期：`"分析 000001 的30分钟缠论"` 或 `"周线分析 000001"`
- 指定数据量：`"分析 000001 最近2000个交易日"`
- 多级别：`"多级别分析 000001"`
- 仅分析不回测：`"只分析不回测 000001"`

## 脚本参数

```bash
python scripts/chanlun_analyzer.py --codes "000001,600519" [选项]
  --period daily|30min|weekly   K线周期（默认daily）
  --count N                     K线数量（默认1000）
  --no-backtest                 禁用回测
  --multi-level                 多级别联合分析（日线+30分钟）
```

## 边界情况

- 代码无效/停牌：提示用户检查
- 上市不足60个交易日：数据不足，提示用户
- 横盘无明确趋势：如实告知中枢震荡
- AKShare不可用：自动降级新浪（数据量可能减少至500根），最多重试3次
- 回测无信号：显示"信号不足，无法回测"
- 周线数据不足：提示用户该股票上市时间较短，建议用日线
